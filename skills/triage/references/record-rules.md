# Record rules

- Decisions (answers that settle a question) -> decisions file.
- Status and confirmations -> progress log.
- New work items (bugs, ideas, implied work) -> tracker.
- "Use X everywhere" or any answer implying a code sweep: record the decision AND route the sweep as an item.
- "Done by the user" confirmations: record as "not yet verified" and add a verify line to OWED BY YOU.
- No-build records (pure decisions or confirmations) get no priority number.
- Live decisions go to LIVE, not to the decisions file; a tick never closes one.
