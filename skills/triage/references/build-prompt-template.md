# Build prompt template

Paste-ready. Fill every part; the new session sees nothing else.

```
[P<n>] <short title>

GOAL: <one sentence: the outcome, not the method>

DECISIONS IN FORCE: <answers already given, each with its date; do not reopen>

READ FIRST: <exact file paths, in order>

SCOPE: In: <what to change>. Out: <what to leave alone>.

REVIEW TIER: <Quick | Standard | Critical>

REPORT BACK: <one line to return, e.g. "built, tests green, branch <name>, owed: <list>">
```
